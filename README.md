## 🚀 Cómo empezar
1. clonar repositorio

```bash
git clone https://github.com/cri191/IPSS-DIPLOMADO-CURSO3-Evaluacion-Final.git
cd IPSS-DIPLOMADO-CURSO3-Evaluacion-Final
npm install 
```
2. crear un archivo ".env" en la raiz tomando de referencia ".env.example" y coloca la cadena de conexion a MongoDB
--bash
instala npm install dotenv
---

3. Levanta el servidor:

```bash
npm run dev
```
si dice conectado a mongo es que ya estas conectado a la base de datos cursos
Si ves `✅ API escuchando en http://localhost:3000`, ya está. Entra a
`http://localhost:3000/` y deberías ver `{ "ok": true, ... }`.
